# DTO-szerződések

Azonosítók: JSON egész szám / Java Long. Az enumok angol, nagybetűs kódok; a frontend magyar feliratot jelenít meg. Az időpont ISO-8601 offsettel, válaszban UTC. A ? opcionális mezőt jelöl. A requestek nem fogadnak id, tulajdonos, hash vagy tetszőleges állapotmezőt. DTO-k Java recordok; minden létrehozás 201, olvasás/módosítás 200, törlés/kijelentkezés 204, ha az API-terv nem ír mást.

A ReservationMapper és AuditEventMapper a kapcsolódó entitásokat is MapStructtal képezi; a bemeneti DTO nem állíthat tulajdonost, állapotot vagy döntési metaadatot.

## Hibaválasz

Content-Type: application/problem+json. Mezők: type (urn:eszkozpont:problem:KOD), title (magyar), status (HTTP), detail (magyar), instance? (kérésútvonal), code (stabil angol kód), errors:[{field,message}]. A rejectedValue, stack trace, SQL és jelszó nem része a válasznak. Security-szűrő hibája is ezt a formát használja.

400: VALIDATION_ERROR, INVALID_REQUEST, INVALID_FILTER, INVALID_SORT, INVALID_PAGE, INVALID_PERIOD, REASON_REQUIRED. 401: INVALID_CREDENTIALS, UNAUTHORIZED, INVALID_TOKEN. 403: ACCESS_DENIED, SELF_APPROVAL. 404: EQUIPMENT_NOT_FOUND, RESERVATION_NOT_FOUND. 409: EMAIL_TAKEN, DATA_CONFLICT, RESERVATION_CONFLICT, INVALID_TRANSITION, STALE_VERSION, EQUIPMENT_UNAVAILABLE, REQUESTER_DISABLED, CONCURRENT_CHANGE. A LAST_ADMIN hibakód még tervezett.
